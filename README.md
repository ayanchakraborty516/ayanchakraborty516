## About me

I'm **Ayan**, a full-stack developer building web applications with the **MERN stack**. My projects bring together responsive interfaces, backend APIs, and persistent data—from team productivity tools to AI chat and travel experiences.

- **Frontend:** React interfaces, reusable components, and clear interaction states.
- **Backend:** REST APIs, authentication, database models, and real-time features.
- **Product focus:** Practical workflows that help people organize, communicate, and get things done.
